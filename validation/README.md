# Student-t precision references

`student_t_975.csv` was generated by base R 4.6.0 (2026-04-24 ucrt), using
`qt(0.975, df)` for integer degrees 1–100 and 128, 256, 512, 1000, 10000 and
1000000. Regenerate from the repository root with
`Rscript validation/generate_t_reference.R`. R is needed only to regenerate
these development references; the application and its tests remain Python
standard-library only.

[R's distribution documentation](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/TDist.html)
defines `qt` and its probability convention. Tests separately derive df=1 from
the Cauchy distribution and df=2 from its analytic CDF. A synthetic equal-effect
three-study example checks the resulting floored Knapp–Hartung interval against
the independent df=2 closed form at absolute tolerance `1e-6`.

The former rounded table exceeded `1e-6` for several degrees, including df=2.
The table now retains the reference precision, and the expansion starts from a
full-precision Normal quantile. Pooling still uses Paule–Mandel; only inaccurate
REML labels in the engine docstrings were corrected. Statistical methods were
not substituted. This does not validate any example trial data or clinical claim.

| Clinical conclusions | Not part of this change | No clinical validation claimed |
